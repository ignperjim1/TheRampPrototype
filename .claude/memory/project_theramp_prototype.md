Prototipo de The Ramp (https://store.steampowered.com/app/1506510/The_Ramp/) como prueba técnica.

**Why:** Es la entrega de una prueba de selección. El estudio valorará explícitamente UX, game feel y "juicy". No es producción, es un prototipo cuyo objetivo es transmitir intención y calidad de ejecución.

**How to apply:**
- Priorizar siempre game feel sobre features extra: cámara, anticipación, impacto, partículas, screen shake, audio, easing, etc.
- Simplificar el alcance al máximo siguiendo el brief: 1 rampa grande, 2-3 trucos, skate sin personaje, movimiento lateral automático, salto automático, swipe en el momento justo para el truco.
- Control único: ratón (simulando dedo), porque el revisor jugará en editor con ratón.
- Plazo: 2 semanas desde el inicio del sprint.
- Entrega: zip del proyecto sin la carpeta `Library`.

Ver también [[project-brief-tecnico]] para restricciones técnicas duras.
